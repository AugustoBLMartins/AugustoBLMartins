# 📂 Projetos em Destaque

## 🎬 CentralDeTv

Sistema desenvolvido para centralizar e otimizar processos de produção audiovisual.

A aplicação nasceu de uma necessidade real dentro de uma central de televisão, com o objetivo de organizar conteúdos, facilitar pesquisas no acervo e melhorar o planejamento de roteiros antes das gravações.

### Principais funcionalidades:

- 📁 Gerenciamento de biblioteca de vídeos e conteúdos
- 🔎 Pesquisa avançada por título, categorias, tags e responsáveis
- 📝 Criação e organização de roteiros de programas
- ⏱️ Controle de tempo dos blocos de programação
- 🔐 Sistema de autenticação e controle de acesso
- 🐳 Ambiente preparado com Docker
- ⚡ Arquitetura Full Stack com frontend e backend separados

### Tecnologias utilizadas:

- React + TypeScript + Vite
- FastAPI + Python
- SQLAlchemy
- SQLite/PostgreSQL
- Docker
- Electron

O projeto representa minha busca por desenvolver aplicações que unem tecnologia e necessidades reais de negócio.
